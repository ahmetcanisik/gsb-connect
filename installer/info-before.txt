GSB Connect
===========

This is a personal login-automation tool for the GSB WiFi captive portal. It
signs in with YOUR OWN credentials, exactly as you would in the browser login
form, and can optionally enable Cloudflare WARP afterwards. It is not a security
bypass.

What this installer does
------------------------
- Installs a single application to Program Files.
- Creates a Start Menu shortcut (and, optionally, a desktop shortcut).
- Does NOT include any credentials. On first run the app creates its own
  per-user configuration file in your account's app data folder
  (%APPDATA%\GSBConnect). On Windows, saved credentials are encrypted with the
  Windows Data Protection API (DPAPI), tied to your user account.

Verify what you are running
---------------------------
This is open-source freeware. You can read the full source code and build it
yourself from the project repository listed on the previous page (the publisher
URL). This program is not code-signed, so Windows SmartScreen may show a warning
the first time you run it; this is expected for new, unsigned freeware.
